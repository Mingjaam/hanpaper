분야 맞춤 번역

논문 분야를 먼저 파악해 한국 학계에서 실제로 쓰는 용어로 옮겨요. 용어집은 직접 고치고 그 용어가 든 문단만 다시 번역할 수 있어요.

레이아웃 그대로

그림·표·수식·색은 원본 그대로 두고 글만 한국어로 바꿔요. 2단 편집, 그림을 둘러싼 문단, 단을 넘는 문단까지 맞춰 조판합니다.

⇆

모두 연결된 화면

읽기 화면에서 문단을 누르거나 드래그하면 원문·번역 PDF의 같은 자리가 함께 표시돼요. 스크롤도 함께 움직입니다.

∑

수식·알고리즘은 원형대로

수식, 식 번호, 수도코드는 번역하지 않고 그대로 보존해요. 읽기 화면에서도 깨지지 않게 이미지로 보여 줍니다.

논문 도우미

"핵심 기여가 뭐야?", "이 식이 뭘 뜻해?" 논문 전체를 아는 도우미가 답하고, 근거 문단 ¶ 표시를 누르면 그 자리로 이동해요.

✎

형광펜과 PDF 저장

중요한 문단에 형광펜을 긋고 한글 논문, 원문, 원문|번역 대역본을 PDF로 저장해요.

LAYOUT

원문 옆에 놓아도
어색하지 않은 한글 논문

한글 PDF는 원본 위에 글자만 바꿔 얹는 방식이라 쪽수와 배치가 원문과 1:1로 맞습니다.

  • 본문 글꼴 크기·정렬·들여쓰기·색 유지
  • 글이 길어지면 빈 공간으로 먼저 늘리고, 그래도 넘칠 때만 줄여요
  • 그림 안 글자, 저자 이름, 참고문헌처럼 번역이 필요 없는 건 그대로
  • 표는 칸마다 번역해 표 모양을 지켜요

  • 문단마다 다시 번역 · 직접 고치기 · 질문하기

FAQ

자주 묻는 질문

비용이 드나요?

앱은 무료입니다. 번역과 질문은 선택한 AI를 쓰므로, PC에 로그인된 Claude Code나 Codex를 쓰면 그 구독 안에서, API 키를 쓰면 사용량만큼 과금됩니다. 논문 한 편(10쪽 안팎)은 보통 2~3분 걸려요.

논문 파일이 외부로 나가나요?

PDF는 내 PC에서 분석하고, 번역할 문단 글자만 선택한 AI(Claude 또는 OpenAI)로 보냅니다. 번역 결과와 형광펜은 내 PC 사용자 폴더에만 저장돼요.

스캔한 PDF도 되나요?

글자를 선택할 수 있는 PDF(대부분의 학술지·arXiv 논문)를 대상으로 합니다. 이미지로만 된 스캔본은 아직 지원하지 않아요.

번역이 마음에 안 드는 문단은요?

문단에서 '다시 번역'(요청 문구를 붙일 수 있어요)이나 '직접 수정'을 누르면 한글 PDF가 그 자리에서 다시 조판됩니다. 용어집을 고치면 해당 용어가 든 문단만 다시 번역해요.

설치할 때 경고가 떠요.

macOS 앱은 Apple Developer ID로 서명·공증되어 처음 열 때 "인터넷에서 받은 앱" 확인만 한 번 뜹니다. Windows에서 "Windows의 PC 보호" 파란 창이 뜨면 '추가 정보' › '실행'을 누르세요(Windows 코드 서명은 아직 없어요).
